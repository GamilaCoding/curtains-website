**Professional Website Design & Development for a Luxury Curtains Company**  

**Overview:**  
I designed and developed a modern and visually appealing website for "Setair," a company specializing in selling and installing luxury curtains. The website is built with cutting-edge technologies and offers the following features:  

✅ **Responsive Design:** Seamlessly adapts to all devices (smartphones, tablets, and desktops).  
✅ **User-Friendly Interface:** Intuitive navigation for an effortless browsing experience.  
✅ **Attractive Product Display:** High-quality images and detailed descriptions of the curtain collection.  
✅ **Hero Slider:** Showcases top products and offers in an engaging way.  
✅ **Dedicated Sections:** Includes "About Us," "Our Products," "Why Choose Us," and more.  
✅ **Consultation Request Form:** Allows customers to easily request a free consultation.  
✅ **Social Media Integration:** Direct links to the company’s social media pages.  
✅ **WhatsApp Quick Contact Button:** Enables instant communication with the sales team.  
✅ **SEO Optimization:** Enhanced search engine visibility for better reach.  
✅ **High Loading Speed:** Optimized for fast and smooth performance.  

**Technologies Used:**  
🚀 **React.js / Next.js** for frontend development  
🎨 **Tailwind CSS** for modern styling  
🌀 **Framer Motion** for smooth animations  
⚡ **Vercel Integration** for fast and secure deployment  

**Outcome:**  
A sleek, high-end website that reflects the elegance and quality of the company's products, helping attract more customers and boost sales. 🚀
